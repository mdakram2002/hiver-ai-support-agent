# Processed Data

This directory contains processed data files generated by the data pipeline scripts:

- `threads.csv` - Cleaned and reconstructed conversation threads
- `train_threads.csv` - Training set (conversation-level split, no leakage)
- `eval_threads.csv` - Evaluation set (conversation-level split, no leakage)
- `intent_review.json` - Sample messages for human taxonomy review
- `intent_taxonomy.json` - Human-approved intent taxonomy
- `resolution_pairs.csv` - Candidate customer-agent resolution pairs
- `resolution_pairs_labeled.csv` - Resolution pairs with intent labels
- `resolution_pairs_embedded.csv` - Resolution pairs with 1536-dimension embeddings
- `labeling_metadata.json` - Metadata about intent labeling process
- `import_metadata.json` - Metadata about database import process
- `split_metadata.json` - Metadata about train/eval split
- `dataset_verification.json` - Dataset verification results
- `eda_summary.json` - Exploratory data analysis summary

All files are generated by the numbered scripts in `data-pipeline/scripts/`.
